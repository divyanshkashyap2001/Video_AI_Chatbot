# Video AI Chatbot

A Python-based AI chatbot that helps users understand YouTube video content.

## Features
- YouTube video link support
- Video transcript extraction
- AI-powered question answering
- Video summarization

## Technologies Used
- Python
- Flask
- Ollama
- YouTube Transcript API
- yt-dlp
- HTML and CSS

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

Make sure Ollama is installed and the model used by the application is available.

## Run the Project

```bash
python app.py
```
